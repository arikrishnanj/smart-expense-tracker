# 💰 Smart Expense Tracker

A responsive web app to track daily expenses, budget and balance with charts using HTML, CSS, JavaScript and Bootstrap.

🔗 **Live Demo:** https://arikrishnanj.github.io/smart-expense-tracker/

## ✨ Features
- Add Income & Expense
- Track Total Balance, Income & Savings
- Category wise Filter (Food, Travel, Shopping, etc.)
- Monthly Expense Charts
- Search & Delete Transactions
- Fully Responsive - Mobile & Desktop

## 🛠️ Tech Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 🚀 How to Use
1. Open Live Demo link
2. Add your Income / Expense
3. Check Balance & Charts
